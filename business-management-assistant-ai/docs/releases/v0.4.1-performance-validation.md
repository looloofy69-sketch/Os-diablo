## Changes validated in this candidate

### Performance
- Top-k task ranking now uses `heapq.nsmallest` while preserving score and tie-break semantics. This reduces selection work from O(n log n) to O(n log k) for small `k`, with O(k) result storage.
- Briefing queries load only six task columns required by their summaries and ranking.
- Concurrent first model-discovery requests coalesce behind one in-flight refresh.
- Evaluation controls separate model count from examples per model, validate JSONL input, report estimated calls and atomically write results.
- The benchmark script warms both implementations, alternates measurement order, records raw timings and checks top task IDs/reasons on each run.

### Logic and outcome correctness
- Only accuracy values with explicit integer `graded >= 10` are admitted as ranking evidence; legacy scalar scores, accuracy-only objects, boolean/float graded values, undersampled values, and non-finite/out-of-range scores are ignored.
- The connector result contract now includes a typed `outcome_unknown` boolean separate from `retryable`. The approval layer serializes it directly instead of searching free-form detail text.
- HTTP non-2xx connector replies are marked outcome-unknown, and are never automatically retried. A network failure is safe to retry only when the code establishes the request could not have reached the receiver.
- SMTP send-stage transport disconnects/timeouts are explicitly outcome-unknown; failures before connecting and definite rejection before delivery are separate.
- Webhook URL validation rejects whitespace/control characters, embedded credentials, invalid/empty/out-of-range ports, query/fragment delimiters, non-string fields and duplicate normalized route prefixes; direct connector timeouts are finite and bounded.
- Model API and signed action POST clients do not follow redirects, avoiding unvalidated credential or payload forwarding.
- Packaging excludes caches, `.env` files, local DBs, model payloads, evaluation outputs, common private key/certificate files, Terraform state, and credential/private-key directories.
