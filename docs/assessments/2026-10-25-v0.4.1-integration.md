## Candidate changes represented

- Top-k task ranking uses a heap for small result limits while preserving ordering.
- Briefing reads select only the fields required for task summaries.
- Model discovery coalesces concurrent first refreshes.
- Endpoint, connector timeout, webhook route and release-packaging validation are strengthened.
- Connector outcomes carry a typed `outcome_unknown` field; approval persistence does not infer delivery certainty from error-message text.
- Ambiguous webhook/SMTP failures are not automatically retried; HTTP redirects are disabled for model and action POSTs.
- Evaluation data is validated before provider calls, and under-sampled scores do not influence ranking.
